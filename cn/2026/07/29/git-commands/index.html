git 常用命令速记

Mozaitii / 2026-07-29

Git 命令行一段时间不使用容易遗忘，常查常新，把常用的记录在此。

克隆仓库

# HTTPS 方式
git clone https://github.com/用户名/仓库名.git

# SSH 方式（需配置 SSH Key）
git clone git@github.com:用户名/仓库名.git

# 克隆到指定目录
git clone https://github.com/用户名/仓库名.git 目标文件夹

# 浅克隆，只拉取最新版本（省流量省磁盘）
git clone --depth 1 https://github.com/用户名/仓库名.git

# 含子模块的仓库（如本博客的 theme）
git clone --recursive git@github.com:用户名/仓库名.git

# 克隆指定分支
git clone -b 分支名 git@github.com:用户名/仓库名.git

拉取远程更新

# 查看远程有哪些新提交（安全，不会自动合并）
git fetch origin

# 拉取远程代码并自动合并到当前分支（一步到位）
git pull

# 更完整的写法，先 fetch 看变更，再手动合并
git fetch origin          # 查看远程更新
git log origin/main       # 看远程分支的提交记录
git merge origin/main     # 确认后合并到本地

今天就用到了这套流程：git fetch 查看 → git log 确认 → git merge 合并，避免了 git pull 可能带来的意外冲突。

查看提交历史

# 简洁版，一行一个提交
git log --oneline

# 只看最近 N 条
git log --oneline -5

# 查看某个远程分支的提交历史
git log origin/main --oneline -10

# 详细日志含分支图
git log --oneline --graph --all

日常操作

# 查看工作区状态
git status

# 添加文件到暂存区
git add 文件名
git add .              # 添加所有变更

# 提交
git commit -m "提交说明"

# 推送远程
git push origin main

# 一行命令推送新分支到远程并建立追踪
git push -u origin 分支名

分支操作

# 查看本地分支
git branch

# 查看所有分支（含远程）
git branch -a

# 创建并切换到新分支
git checkout -b 新分支名

# 切换分支
git checkout 分支名

# 删除本地分支
git branch -d 分支名

# 删除远程分支
git push origin --delete 分支名

撤销与回退

# 撤销工作区的修改（未 add）
git checkout -- 文件名

# 撤销暂存区（已 add 但未 commit）
git reset HEAD 文件名

# 回退到上一个提交（保留工作区修改）
git reset --soft HEAD~1

# 回退并丢弃工作区修改（谨慎使用）
git reset --hard HEAD~1

其他实用命令

# 暂存当前工作，切换到其他分支干活
git stash
git stash pop          # 恢复暂存

# 查看文件具体变更内容
git diff
git diff --staged      # 查看已暂存的变更

# 绑定远程仓库
git remote add origin git@github.com:用户名/仓库名.git

# 查看远程仓库地址
git remote -v
